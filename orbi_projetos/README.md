# Projetos ORBI

Desenvolvimento de toda estrutura e programação do satélite de modelo _cubesat_ e do _foguete_.

## Mapa de Arquivos

* ```README.md```: Documentação do Projeto
* ```dashboard_interativo.py```: Aplicação de Dashboard Online com Streamlit e Jupyter Notebooks
* ```instrucoes.txt```: Instruções Para Execução do Projeto Localmente
* ```orbi_projetos.ino```: Montagem do Mapa de Pinos e Código fonte do ESP32
* ```orbi_server.sql```: Banco de Dados do Projeto
* ```requirements.txt```: Bibliotecas necessárias para Execução Local
* ```satelite.py```: Integração SQL + ESP32 + Python
